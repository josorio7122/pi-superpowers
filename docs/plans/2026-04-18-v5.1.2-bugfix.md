## Task 3: Pin bundled-agent model to `openai-codex/gpt-5.4`

**Files:** `src/subagents/agent-config-builder.ts` + test, `src/subagents/tool.ts`, `src/index.ts`

Policy:
- `SUPERPOWERS_AGENT_MODEL` env var (valid `provider/model` format) overrides everything.
- Upstream agent file with valid explicit `model: provider/model` → use it.
- Upstream `model: inherit` or missing → use pinned default `openai-codex/gpt-5.4` (NOT `ctx.modelId`).
- Invalid upstream format and no override → throw.

- [ ] Rewrite `describe("buildAgentConfig model resolution", ...)` in `agent-config-builder.test.ts` with cases for pinned default, explicit upstream, env override, and invalid format. Remove the old "throws when 'inherit' and modelId undefined" test (no longer possible).
- [ ] Replace `resolveModel` in `agent-config-builder.ts`:
  - constant `PINNED_DEFAULT_MODEL = "openai-codex/gpt-5.4"`
  - check `SUPERPOWERS_AGENT_MODEL` env var first (validate format, throw on invalid)
  - treat `undefined`/`"inherit"` as default
  - validate explicit upstream against `MODEL_FORMAT`, throw on invalid
- [ ] Remove `modelId` from `BuildCtx`. Remove `modelId` param from all `buildAgentConfig` call sites.
- [ ] Remove `modelId` from `SubagentToolCtx` in `tool.ts`. Remove its assignment in `index.ts`.
- [ ] Update test fixtures that referenced `modelId`.
- [ ] `npm run check`. Commit: `feat(subagents): pin bundled-agent model to openai-codex/gpt-5.4`.
