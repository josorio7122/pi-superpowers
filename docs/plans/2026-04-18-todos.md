# pi-superpowers Todos (M3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship `superpowers_todo` tool + `/todos` interactive command + persistent widget. Releases as `v5.0.8`.

**Architecture:** Pi-native tool with Typebox-validated schema. State reconstructed from session entries (no hidden in-memory). Full TUI rendering via `src/ui/` primitives. Interactive picker via `ctx.ui.custom()`.

**Tech Stack:** Typebox (schema), vitest, pi extension API.

**Reference spec:** `docs/specs/2026-04-18-pi-superpowers-design.md` §8.4, §10.3 (Todos section).
